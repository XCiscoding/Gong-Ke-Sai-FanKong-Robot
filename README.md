# 工科赛机器人代码

按你要验证的模块选分支。

| 模块 | 分支 | 里面有什么 |
| --- | --- | --- |
| 底盘 | [chassis](https://github.com/XCiscoding/Gong-Ke-Sai-FanKong-Robot/tree/chassis) | 完整 STM32CubeIDE 固件工程。已从 GitHub 干净克隆并完成 Debug 编译和链接。 |
| 视觉 | [vision](https://github.com/XCiscoding/Gong-Ke-Sai-FanKong-Robot/tree/vision) | F407 与 K230 的 TEXT TRACK 通讯、脚本和协议。 |

测底盘就打开 [chassis](https://github.com/XCiscoding/Gong-Ke-Sai-FanKong-Robot/tree/chassis)，用 STM32CubeIDE 导入 PBRoBot，选 Debug 构建。默认固件会运行完整路线，首测使用与现场硬件核对过的单段配置。历史快照在 GitHub 的「标签」页。
